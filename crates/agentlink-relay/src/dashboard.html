Machines

Node ids are pinned in this browser after the first visit. A name that changes id is a different key. A CA-only relay certificate does not pin that mapping. The CLI uses AGENTLINK_RELAY_PIN for an optional SPKI or leaf pin.

Enroll a machine

Creates a token and one command. On the new machine that command downloads agentlink, installs it, starts it, and signs it in.

This page enrolls machines and lists them. Shell, files, and desktop are not available in the browser. Control a machine from a sealed client after this node has a grant for that client's key.
