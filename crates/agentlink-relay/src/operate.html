No node guide in this link

The URL fragment is missing or invalid. A guide link looks like /operate/#v1.<base64url>.

Mint a pasteable URL on a machine signed in to the relay, or use the dashboard Guide button:

agentlink guide <node> --print-only

Replace <node> with a name or id, e.g. agentlink guide lab-box --print-only. On the node host use agentlink guide --local --print-only. Without --print-only the CLI opens the page in a browser.

1. Install or update the CLI

Windows PowerShell: irm <origin>/install.ps1 | iex. Keep the CLI and node on the same release when possible.

2. Sign in to the relay

Sign in as the owner or an admin. That session is full access to the machine: shell, files, and desktop. The relay still cannot read the sealed operation payloads.

3. Open the machine

A signed-in owner or admin does not paste a SignedGrant. The commands below are only for a key that is not an account session. Payloads stay sealed; the relay cannot read them. See the E2E trust model.

4. Common operations

Use the node name or the hex id. Add --json for machine-readable output.

5. TCP port forwarding

Both listeners bind loopback. Forward exposes a port on this machine to the node; reverse exposes a node-loopback port to this machine.

7. Limits and safety

  • Effective policy for this caller: unknown. The node's local ceiling can be narrower.
  • Grants expire. Re-issue with agentlink grant issue --node <id> --ttl 1h.
  • Screenshots and remote view need a graphical session. Headless nodes use shell and files.
